## 📖 Project Overview  
This mini project demonstrates how **Green Networking** principles can be used to **reduce power consumption in data transmission**, supporting **SDG 12 – Responsible Consumption and Production**.  

It uses a simple network simulation to visualize **energy consumption before and after optimization**, promoting sustainable digital practices.

---

## 🎯 Objectives  
- Simulate data transmission across a small network.  
- Measure and compare energy usage before and after optimization.  
- Demonstrate energy efficiency with adaptive transmission rates.  
- Raise awareness about sustainable ICT systems and SDG 12.  

---

## ⚙️ Tech Stack  
- **HTML5** – Structure of the web page  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Logic and energy simulation  
- **Chart.js** – Data visualization for energy comparison
